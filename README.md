# Submission: Belajar Dasar Pemrograman Web (IDCamp 2025)

Selamat datang di repository proyek submission saya untuk kelas **"Belajar Dasar Pemrograman Web"** dari Dicoding. Proyek ini adalah sebuah website edukasi statis yang berfungsi sebagai portofolio pribadi dan alat bantu belajar sederhana, dengan topik utama materi **Bilangan Bulat**.

---

## Fitur & Teknologi

Proyek ini dibangun dengan menerapkan berbagai konsep dasar pengembangan web yang telah saya pelajari.

### Fitur Utama
* **Navbar Interaktif:** Tampilan navigasi berubah gaya saat halaman di-scroll.
* **Desain Responsif:** Tampilan website dapat beradaptasi di berbagai ukuran layar, lengkap dengan hamburger menu untuk mobile.
* **Struktur Semantik:** Dibangun menggunakan elemen HTML5 semantik (`<header>`, `<main>`, `<article>`, `<aside>`) untuk meningkatkan aksesibilitas dan SEO.

### Teknologi yang Digunakan
* **HTML5:** Untuk membangun struktur dan konten website.
* **CSS3:** Untuk styling, layouting (termasuk Flexbox), dan membuat desain menjadi responsif.
* **JavaScript:** Untuk memberikan interaktivitas pada website.

---

## Materi yang Dipelajari & Diterapkan

Website ini merupakan implementasi dari materi-materi yang telah saya pelajari selama mengikuti kelas "Belajar Dasar Pemrograman Web" di Dicoding. Berikut adalah rangkuman materi tersebut:

* **Pendahuluan**  
    Pengenalan mengenai website, server dan client, anatomi website, dan tools yang diperlukan dalam pengembangan halaman website.

* **Pengenalan HTML**  
    Mempelajari alat yang digunakan dalam membangun struktur halaman website. Modul ini membahas tentang HTML, struktur dasar dokumen HTML, dsb.

* **Pendalaman HTML**  
    Mendalami penerapan HTML dalam membangun struktur halaman web, seperti penggunaan elemen semantik, atribut, generic element, dan table.

* **Pengenalan CSS**  
    Mempelajari alat yang digunakan untuk memperindah tampilan halaman website, termasuk cara kerja, sintaks, dan anatomi dari CSS rule.

* **Pendalaman CSS**  
    Mendalami penerapan CSS lebih lanjut, seperti variasi selector, styling font dan text, box model, shadow, positioning, dan media query untuk responsivitas.

* **Layout Responsif dengan Flexbox**  
    Mempelajari teknik layouting modern menggunakan Flexbox untuk membangun tata letak yang fleksibel dan responsif.

* **Penutup**  
    Implementasi seluruh teknik yang telah dipelajari dalam pembuatan sebuah proyek website sederhana dari awal hingga akhir.
